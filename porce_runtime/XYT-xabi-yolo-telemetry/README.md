# XYT xabi-yolo-telemetry

Generador 3D procedural ultra rapido. No descarga modelos ni usa IA pesada:
convierte palabras conocidas en conjuntos de primitivas geometricas y exporta
OBJ + MTL casi instantaneamente.

## Uso

Doble clic:

```text
GENERAR_3D.bat
```

O desde consola:

```bat
GENERAR_3D.bat cow
GENERAR_3D.bat biker
GENERAR_3D.bat tree
GENERAR_3D.bat car
GENERAR_3D.bat truck
GENERAR_3D.bat bush
GENERAR_3D.bat tractor
```

El resultado se guarda en esta misma carpeta:

```text
cow.obj
cow.mtl
```

Palabras soportadas: `cow`, `biker`, `tree`, `car`, `truck`.
