# CLASS MAPPING — external sanity check (exploratory, post-hoc)

**Status: written BEFORE any evaluation run.** This file freezes the dataset choice, the
class→family mapping, and the metric scale criteria. Any later change is logged in
`CHANGELOG.md` with a reason.

## 1. Dataset decision

| Option | Verdict | Reason |
|---|---|---|
| ModelNet10 | REJECTED | Furniture only; no overlap with the 6 SPPA-MVFit families. |
| ModelNet40 (Princeton) | PARTIAL | Only `car`→compact_vehicle and `plant`→branching_vertical overlap. |
| ShapeNet mirrors on HuggingFace | REJECTED (as mesh source) | Official `ShapeNet/ShapeNetCore` is gated; non-gated mirrors checked (`kianzohoury/shapenetcore`, `jxie/shapenet55`, `SeaLab/ShapeNet`) contain **point clouds**, not meshes. Verified by probing the zip central directory / READMEs on 2026-07-18. |
| **Objaverse v1 (LVIS subset)** | **CHOSEN (primary)** | Non-gated on HuggingFace (`allenai/objaverse`, verified `gated: false` via API). LVIS annotations give real meshes for all 6 families. GLB per-object download. |
| **ModelNet40 via HF mirror `naderalfares/ModelNet40`** | **CHOSEN (secondary)** | Non-gated, per-file OFF download (no 450 MB zip needed). Used for `car` and `plant` because ModelNet40 is class-aligned and the official `test/` split is a natural held-out set. |

Meshes are **real third-party assets** (3D Warehouse / Sketchfab-style uploads via Objaverse;
Princeton ModelNet40), not generated by the paper's authors.

## 2. Class → family mapping

| SPPA-MVFit family | External class(es) | Source | n target | Match quality |
|---|---|---|---|---|
| `compact_vehicle` | `car` (test split) | ModelNet40 | 8 | strong |
| `articulated_vehicle` | `trailer_truck` (LVIS), `bus_(vehicle)` (LVIS) | Objaverse | 8 (5+3) | strong (semi = tractor+trailer) / moderate (bus: rigid long vehicle) |
| `quadruped` | `horse`, `dog`, `cow` (LVIS) | Objaverse | 9 (3+3+3) | strong |
| `branching_vertical` | `Christmas_tree` (LVIS), `plant` (test split) | Objaverse + ModelNet40 | 8 (4+4) | moderate (conifer ≈ trunk+layered crown; potted plant ≈ trunk+crown) |
| `lattice_tower` | `water_tower`, `clock_tower` (LVIS) | Objaverse | 8 (4+4) | moderate–weak (water tower: legs+tank; clock tower: solid masonry — mapped because it is the closest real "tower" class) |
| `rider_cycle` | `motorcycle`, `bicycle` (LVIS) | Objaverse | 8 (4+4) | moderate (real meshes have **no rider**; family graph includes rider torso/head) |

Total target: **49 meshes** (within the declared 30–60 scope). ~1.5× candidates are
downloaded to allow QC rejects; the final selection is fixed in `manifest.json`.

## 3. Metric scale criteria (declared a priori)

Benchmark world box: x∈[-4.8, 4.8], y∈[-3.2, 3.2], z∈[0, 6.4] m (`protocol_config.json`).
Each mesh is uniformly scaled so its extent along the declared reference axis equals the
declared metric size, then clamped to fit the world box with ≥0.2 m margin.

| Class | Reference axis | Declared size | Rationale |
|---|---|---|---|
| car | length (x) | 4.4 m | compact sedan |
| trailer_truck | length (x) | 8.8 m | semi truck, clamped to world |
| bus | length (x) | 8.8 m | city bus compressed to world box |
| horse | length (x) | 2.4 m | nose-to-tail |
| dog | length (x) | 1.1 m | medium dog |
| cow | length (x) | 2.4 m | cattle body |
| Christmas_tree | height (z) | 3.6 m | large conifer |
| plant (ModelNet40) | height (z) | 2.2 m | large potted/indoor tree |
| water_tower | height (z) | 5.5 m | matches benchmark tower range 3.25–5.75 m |
| clock_tower | height (z) | 5.8 m | idem, clamped |
| motorcycle | length (x) | 2.2 m | typical motorcycle |
| bicycle | length (x) | 1.85 m | typical bicycle |

After scaling: center x,y at (0,0); bottom of bounding box at z=0 (ground plane, as in the
benchmark's `validate_actor_inside_world`).

## 4. Orientation convention

Benchmark convention (`graphs.json`, `source_generators.py`): **+x = front/length, +y = width,
+z = up**, objects rest on z=0.
- ModelNet40: class-aligned OFF; the per-class rotation is determined once from QC renders
  and applied uniformly (logged in `manifest.json`).
- Objaverse GLB: glTF +Y-up assumed as first hypothesis; yaw resolved by PCA of the
  horizontal vertex distribution (longest horizontal axis → x). Front/back sign ambiguity of
  ±180° is accepted (family graphs are near front-back symmetric) and noted as a limitation.
  All candidates go through visual QC (top/side mask contact sheets); failures are rejected
  or corrected via per-case overrides logged in `orientation_overrides.json`.

## 5. Condition

Primary: **clean** (exact masks from the meshes). Secondary robustness probe:
**mild_morphology** (1 morphology iteration, same `_morph` operator as the sealed
`benchmark.run_benchmark.make_conditions`, imported — not re-implemented).

## 6. Known limitations (declared a priori)

- n is small (≈8/class); this is a sanity check, not a benchmark.
- Class→family mapping is approximate for lattice_tower, rider_cycle, branching_vertical.
- Objaverse meshes vary in quality, scale semantics and orientation; QC-based rejection
  introduces a selection bias (documented counts in README).
- GT voxelization uses ray-parity filling; open/non-manifold meshes may voxelize with
  artifacts — mitigated by QC and fill-ratio sanity bounds.
- Metric sizes are declared constants per class, not measured per instance.
