## External Context

- [HY3D-Bench](https://github.com/Tencent-Hunyuan/HY3D-Bench): Provides a recent open benchmark/data ecosystem with clean meshes, renderings, sampled points, and part-level data useful for image-to-3D evaluation.
- [Hunyuan3D-2.1](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1): Recent open image-to-3D system with full model weights/training code and PBR texture synthesis, so it belongs in any serious contemporary comparison or must be explicitly excluded.
- [TRELLIS.2](https://github.com/microsoft/TRELLIS.2): Recent open 4B-parameter image-to-3D model for high-fidelity PBR textured assets; a 2026-era SOTA comparison should run it or document a hardware/reproducibility exclusion.
- [Stable Fast 3D](https://github.com/Stability-AI/stable-fast-3d): Fast feed-forward single-image mesh reconstruction baseline with UV unwrapping and material prediction; useful for separating SPPA runtime claims from fast visual reconstruction baselines.
- [SPAR3D](https://github.com/Stability-AI/stable-point-aware-3d): Point-aware successor to SF3D with improved backside reconstruction and materials; should be included or explicitly excluded when claiming contemporary image-to-3D coverage.
- [P3D-Bench](https://spatiaos.github.io/projects/P3D-Bench/): Recent benchmark framing for parametric 3D generation and structural reasoning, including image-to-3D and part/assembly-level metrics.
