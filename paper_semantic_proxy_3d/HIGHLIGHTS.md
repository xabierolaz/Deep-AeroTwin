# Highlights (journal-facing)

1. **Novelty:** A frozen semantic-family part graph is a *measurable* 3D occupancy prior for lightweight multiview proxy fitting (family-conditioned SPPA-MVFit), isolated by equal-budget comparison to a nonsemantic graph—not a new neural reconstructor.
2. **Protocol:** Preregistered, NIST-bound, sealed held-out test (n=240; CSG-ID + implicit-OOD); H1 uses stratified bootstrap CI lower bound > +0.030.
3. **Result:** Mean voxel-IoU gain +0.190 (95% CI [0.181, 0.199]); all 12 family×stratum cells positive; OOD stratum +0.172.
4. **Use case:** Sparse UAV semantic telemetry → low-polygon, role-labeled twin proxies with millisecond local build and explicit fallback (deployment context, secondary).
5. **Boundary:** Synthetic internal evidence only; no claim of photoreal image-to-3D SOTA, measured flight GT, or operator benefit.
