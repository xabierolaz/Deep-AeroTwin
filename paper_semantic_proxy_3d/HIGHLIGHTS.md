# Highlights — for JGSA (Springer)

1. **Spatial novelty:** A frozen semantic-family part graph is a *measurable* 3D occupancy prior for lightweight multiview proxy fitting (SPPA-MVFit), isolated by equal-budget comparison to a nonsemantic graph.
2. **Sealed protocol:** Preregistered, NIST-bound held-out test (n=240; CSG-ID + implicit-OOD); H1 requires stratified bootstrap CI lower bound > +0.030.
3. **Result:** Mean voxel-IoU gain +0.190 (95% CI [0.181, 0.199]); all 12 family×stratum cells positive; OOD stratum +0.172.
4. **Twin use case (secondary):** Sparse UAV semantic telemetry → role-labeled low-polygon proxies (~685 tris, ~0.22 ms local build under balanced LOD).
5. **Boundary:** Synthetic developer-held-out evidence only; not photoreal image-to-3D SOTA, not measured flight GT.
