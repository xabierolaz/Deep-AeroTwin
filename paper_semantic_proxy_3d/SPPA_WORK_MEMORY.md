## Paper Rule

The manuscript tables should not use `PENDING-*` tags or read like a task board.
Use this file for internal tracking. In the paper, tables should show only:

- design alternatives,
- implemented artifacts,
- measured results,
- experimental protocols,
- claim boundaries.

Geometry-only primitives are negative controls and lower-bound runtime
references, not primary scientific competitors. Do not present isolated
box/capsule/ellipsoid construction timings as a result. Component-level SPPA
views belong in the technical supplement unless the figure directly supports a
specific main-paper claim; the primary visual comparison in the main manuscript
should be against operational alternatives such as curated assets and fast
text/image-to-3D generators.

## HISM Partial-Update Decision

2026-07-03: Implemented and verified `partial_obstacle_update=true` for the
opt-in HISM backend. The actor now preserves unmentioned entities and removes
stale instance keys for mentioned entities before upserting new parts. Backend
verification creates two entities, updates one with a reduced part set, and
verifies 6/6 expected live/HISM instances.

Packaged evidence is conditional:

- Dense 100-object shape updates still fail: `20260703T040154Z_packaged_render`
  reports shape-stream P95 46.151 ms.
- Sparse shape updates with dense pose updates are not enough at 250/500 objects:
  `20260703T040406Z_packaged_render` reports pose-stream P95
  52.474/104.502 ms at 250/500.
- A synthetic 10% pose + 10% shape changed-track schedule passes 30 FPS P95
  through 500 objects: `20260703T040602Z_packaged_render` reports 500-object
  pose/shape P95 16.528/29.787 ms, 11 draw groups, and no hitches above 33 ms.

Paper claim wording: "partial updates support a changed-only scheduler stress
case"; do not claim dense all-object update scalability or flight-derived update
frequency.

## Current Defensible Claim

SPPA is a deterministic, local, part-based semantic proxy representation for sparse UAV semantic telemetry. It is not a general 3D generator, not a flight pipeline, not a safety system, and not yet a tested pilot-facing VR representation.
